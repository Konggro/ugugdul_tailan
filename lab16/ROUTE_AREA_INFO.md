# Замын сүлжээний бүс

## Анхаар

Одоогийн замын сүлжээ нь **жижиг тест өгөгдөл** ашиглаж байна.

### Замын сүлжээний хэмжээ:

- **Бүс:** (0, 0) - (10, 10)
- **Зангилаанууд:**
  - Node 1: (0, 0)
  - Node 2: (10, 0)
  - Node 3: (10, 10)
  - Node 4: (0, 10)

### Замууд:

1. **Road 1:** (0, 0) → (10, 0) - Доод
2. **Road 2:** (10, 0) → (10, 10) - Баруун
3. **Road 3:** (10, 10) → (0, 10) - Дээд
4. **Road 4:** (0, 10) → (0, 0) - Зүүн
5. **Shortcut:** (0, 0) → (10, 10) - Диагональ

## Ашиглах

### Зөв цэгүүд:

- Эхлэх цэг: (0, 0) эсвэл ойролцоо
- Очих цэг: (10, 10) эсвэл ойролцоо

### Буруу цэгүүд:

- (50, 50) - Замын сүлжээний гадна
- (100, 100) - Замын сүлжээний гадна

## "No route found" алдаа

Хэрэв энэ алдаа гарвал:

1. **Шалгах:** Цэгүүд замын сүлжээний бүс дотор байгаа эсэх
2. **Шийдэл:** Цэгүүдийг (0, 0) - (10, 10) бүс дотор сонгох

## Бодит OSM өгөгдөл ашиглах

Бодит OpenStreetMap өгөгдөл ашиглахын тулд:

1. OSM файл татах
2. `osm2pgsql` ашиглан импорт хийх
3. Замын сүлжээг pgRouting-д тохируулах

Дэлгэрэнгүй: `README.md` файлд "OpenStreetMap өгөгдөл ашиглах" хэсэг.
