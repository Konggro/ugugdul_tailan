# Lab15 - 15 минутын хот: Хот төлөвлөлт

## Тайлбар

Энэхүү аппликейшн нь "15 минутын хот" концепцийг хэрэгжүүлж, Улаанбаатарын хорооллуудын хүртээмжийг шинжилдэг.

## Концепц: 15 минутын хот

Өөрийн гэрээсээ гараад 15 минутын дотор:
- Сургууль, цэцэрлэг
- Дэлгүүр, эмийн сан
- Парк, амралтын газар
руу алхаад эсвэл дугуйгаар хүрэх боломжтой байх.

## Технологи

- **Leaflet.js**: Газрын зураг
- **OpenRouteService (ORS)**: Isochrone тооцоолол
- **Leaflet.heat**: Heatmap (авто ослууд)
- **Leaflet.markercluster**: Marker clustering (ЕБС, эмийн сан)
- **Turf.js**: Гео-анализ

## Функцүүд

### 1. Хороолол сонгох
- 36-р хороолол
- 15-р хороолол
- 1-р хороолол
- Баянгол дүүрэг

### 2. 15 минутын Isochrone
- Алхах хугацааны бүс харуулах
- OpenRouteService API ашиглах

### 3. Heatmap (Авто ослууд)
- Leaflet.heat ашиглан нягтралын зураг
- Улаан = өндөр нягтрал
- Шар = дунд нягтрал
- Цэнхэр = бага нягтрал

### 4. Marker Clustering
- **ЕБС-ууд**: Clustering ашиглан харуулах
- **Эмийн сангууд**: Clustering ашиглан харуулах
- Ойрхон цэгүүд автоматаар бүлэглэгдэнэ

### 5. Анализ
- 15 минутын бүс дотор хэдэн ЕБС байгаа
- Хэдэн эмийн сан байгаа
- Хэдэн авто осол гарсан
- "15 минутын хот" стандарт хангаж байгаа эсэх
