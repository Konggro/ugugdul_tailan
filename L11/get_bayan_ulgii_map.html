Баян-Өлгий аймгийн газрын зургийг PNG болгох заавар

  1. Доорх газрын зураг дээр Баян-Өлгий аймгийг төвлөрүүлнэ
  2. Browser-ийн Developer Tools (F12) нээнэ
  3. Console дээр дараах командыг ажиллуулна: html2canvas(document.getElementById('map')).then(canvas => { const link = document.createElement('a'); link.download = 'BayanUlgii_aimag.png'; link.href = canvas.toDataURL(); link.click(); });
  4. Эсвэл screenshot хийж, газрын зургийг зөвхөн сонгоод хадгална
  5. PNG файлыг L11/Data/BayanUlgii_aimag.png гэж хадгална

Анхаар: OpenTopoMap layer-ийг сонгоод, zoom level-ийг тохируулна уу (zoom 7-9 зохимжтой)
